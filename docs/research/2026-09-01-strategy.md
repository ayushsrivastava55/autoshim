# Autoshim — market strategy synthesis (2026-09-01)

Inputs: 4 research agents (competitors+funding, trending OSS, Context.dev, YC), 2026-09-01.
Full agent findings summarized here; secondary-source items flagged inline by the agents.

## Market read
- Category validated and explicitly named by YC's Fall 2026 RFS: "Self-Maintaining APIs"
  (Harsha Gaddipati) — agents that scan codebases for breaking API changes and open fix PRs.
- No funded company owns it yet. 6 indie attempts (apidrift.co, apidrift.dev, mendapi,
  changeguard, breakwatch.ai, apiguard[dead]) — none with funding or visible traction.
- Expect a wave of YC-backed entrants within 2–3 quarters (the RFS advertises the idea).
  Speed-to-default-OSS-choice > differentiation now.
- Validation of strategic value: Anthropic acquired Stainless (~$300M, May 2026);
  Versori (YC W23, $11.5M) does "self-healing agents" for enterprise iPaaS — adjacent, not dev-PR.
- Infield ($5.9M) stays in OSS-package upgrades; Moderne ($50M) enterprise refactoring;
  Optic dead; Grit absorbed into Honeycomb.

## How we win (edge vs each)
1. **Generic OpenAPI spec-diff** — every competitor watches a curated list (3–26 vendors);
   none accepts an arbitrary spec URL. Deterministic diffs beat LLM changelog-scraping on
   trust, and trust is the product (one wrong auto-PR kills adoption).
2. **Apache-2.0 OSS CLI + public packs registry** — the Renovate playbook. Competitors are
   closed SaaS (mendapi: AGPL scanner only). Per-vendor knowledge compounds in public and
   accrues to us as network effect; a closed rival can't replicate a community.
3. **MCP server** — 400M+ monthly MCP SDK downloads, 8–12k servers (Q2 2026); Claude Code /
   Cursor / Copilot are where the buyer lives. mendapi already ships one → we must too, in v1.
4. **Neutral third-party position** — the RFS itself notes vendors can only fix their own API;
   cross-vendor coverage is structurally ours.
5. **JS/TS + Python healing** (apidrift.co is TS-only).

## Business model (unchanged from PRD, sharpened)
Free OSS CLI (land) → hosted GitHub App $29 Pro / $99–149 Team (fanout, scheduling,
dashboard, Slack) → enterprise/compliance later (mendapi's fintech angle shows demand).
One-liner: **"Renovate for the APIs you don't control."**

## Context.dev (confirmed)
- YC S26, founder Yahia Bakour; 400+ customers (Mintlify, Klarna). Monitors launched in
  beta 2026-07-09 — young; our ChangeSource abstraction keeps them limited to page targets
  (specs + releases are local polling), which caps the dependency risk.
- Economics: page run = 1 credit, semantic extract = 10 credits. 20 vendors @ 6h semantic
  ≈ 24k credits/mo ≈ **$46/mo** (Developer $25 + overage). 30% startup discount on paid plans.
  Hosted product margin is fine; OSS users bring their own key (per PRD §16).
- Rate limits fine at our scale (Developer: 60 calls/min, 50 concurrent monitors).

## Distribution plan (2026 playbook)
1. Ship OSS with a 60-second wow: `npx autoshim init` → paste OpenAPI URL → simulated
   breaking change → draft PR. GIF on README.
2. MCP server (`autoshim mcp`: scan/watch/impact/heal tools) + MCP directory listing.
3. Show HN Tue–Thu 8–10am ET; X thread; DevHunt; Indie Hackers milestone posts.
4. GitHub Action wrapper early (CI is where watch --once naturally runs).
5. Packs as contribution surface — "add your vendor" PRs = community flywheel.
